## 추가 방법

1. `problems/<사이트>_<번호>_<제목>/` 폴더를 만든다.
   예: `boj_11720_sum_of_digits/`, `programmers_42576_incomplete_runner/`
2. 안에 `<폴더 이름>.md`(풀이 정리)와 `<폴더 이름>.cc`(제출 코드)를 넣는다.
3. 위 표에 한 줄 추가한다. 사용한 패턴은 `patterns/` 문서로 링크한다.

## 풀이 정리 목차

1. 문제 요약
2. 입력·출력 형식과 제한 조건
3. 접근 방법 (어떤 패턴·알고리즘을 쓰는지, 왜 그런지)
4. 코드
5. 시간 복잡도
6. 틀린 부분과 회고
