## 0. 배경

**개념**
숫자 모양의 문자 `'0'`~`'9'`를 실제 정수 `0`~`9`로 바꾸는 식이다.

**목적**
코딩테스트 입력은 숫자를 문자열로 주는 경우가 많다.

- `"98765"`처럼 공백 없이 붙은 숫자 → 각 자리수를 따로 계산해야 함
- `"0110"`처럼 줄 단위로 주어지는 격자(지도) 입력
- `long long` 범위를 넘는 큰 수

이런 입력은 `string`으로 받은 뒤 한 글자씩 꺼내 `c - '0'`으로 바꿔서 쓴다.

> `char` 변수 `c`에 `'3'`이 들어 있으면 그 값은 정수 3이 아니라 **문자 코드 51**이다.
> 그대로 더하거나 비교하면 엉뚱한 값이 나온다.

---

## 1. 문법

```cpp
char c = '3';
int n = c - '0';   // n == 3
```

| 표현 | 의미 |
|---|---|
| `c` | 숫자 문자 (예: `'3'`) |
| `'0'` | 숫자 0을 나타내는 문자 (작은따옴표 = 문자 한 개) |
| `c - '0'` | 두 문자의 코드값 차이 → 한 자리 정수 |

> **새 문법: 작은따옴표 vs 큰따옴표**
> `'0'`은 문자 한 개(`char`), `"0"`은 문자열(`string`)이다. `c - "0"`은 컴파일 에러가 난다.

---

## 2. 동작 원리

`'0'`~`'9'`는 문자 코드가 연속으로 붙어 있다.

| 문자 | `'0'` | `'1'` | `'2'` | `'3'` | ... | `'9'` |
|---|---|---|---|---|---|---|
| ASCII 코드 | 48 | 49 | 50 | 51 | ... | 57 |

그래서 `'3' - '0'` = `51 - 48` = `3`이 된다.
C++ 표준이 숫자 문자의 연속 배치를 보장하므로 ASCII가 아닌 환경에서도 성립한다.

```cpp
char c = '3';
cout << c << '\n';        // 출력: 3   (문자로 출력)
cout << (int)c << '\n';   // 출력: 51  (문자 코드)
cout << c - '0' << '\n';  // 출력: 3   (정수)
// c - '0'을 계산해도 c는 여전히 char '3'
```

> **새 문법: `(int)c`**
> 괄호 안의 자료형으로 값을 바꿔서 보는 형변환(캐스팅)이다. 문자 코드를 확인할 때 쓴다.

> **정수 승격**
> `char`끼리 빼면 계산 전에 자동으로 `int`로 바뀐다. 그래서 `c - '0'`의 결과는 `int`다.

## 3. 코딩테스트 활용 패턴

### 3-1. 한 글자씩 정수로 꺼내기

```cpp
#include <iostream>
#include <string>
using namespace std;

int main() {
    string s = "123";
    for (char c : s) {
        cout << c - '0' << ' ';
    }
    // 출력: 1 2 3
}
```

> **새 문법: 범위 기반 for문** `for (char c : s)`
> 문자열 `s`의 글자를 앞에서부터 하나씩 `c`에 넣으며 반복한다.

### 3-2. 각 자리수의 합

문제 예시: 공백 없이 주어진 숫자들의 합 구하기 (백준 11720)

```cpp
string digits = "98765";
int sum = 0;
for (char c : digits) {
    sum += c - '0';
}
cout << sum;
// 출력: 35
```

### 3-3. 문자열 → 정수 직접 만들기

```cpp
string number_str = "1234567890123";
long long num = 0;
for (char c : number_str) {
    num = num * 10 + (c - '0');
}
cout << num;
// 출력: 1234567890123
```

앞자리부터 읽으면서 "지금까지 값 × 10 + 새 자리수"를 반복한다.

| 단계 | 읽은 문자 | `num` |
|---|---|---|
| 1 | `'1'` | 0 × 10 + 1 = 1 |
| 2 | `'2'` | 1 × 10 + 2 = 12 |
| 3 | `'3'` | 12 × 10 + 3 = 123 |

`stoi()`로도 되지만 이 방식은 문자열을 읽으면서 다른 계산(나머지 연산 등)을 같이 할 수 있다.

### 3-4. 숫자만 골라서 계산

```cpp
#include <cctype>   // isdigit

string mixed = "a1b2c3";
int total = 0;
for (char c : mixed) {
    if (isdigit(c)) total += c - '0';
}
cout << total;
// 출력: 6
```

### 3-5. 격자(지도) 입력을 2차원 배열로

BFS/DFS 문제에서 가장 자주 쓰는 형태다. 입력이 공백 없이 `0110`처럼 들어오면 `int`로 받을 수 없어서 줄을 `string`으로 받는다.

```cpp
vector<string> rows = {"0110", "1011", "0001"};
int board[3][4];

for (int i = 0; i < 3; i++)
    for (int j = 0; j < 4; j++)
        board[i][j] = rows[i][j] - '0';

cout << board[1][2];
// 출력: 1
```

실제 입력을 받을 때는 이렇게 쓴다.

```cpp
int height, width;
cin >> height >> width;
for (int i = 0; i < height; i++) {
    string row;
    cin >> row;
    for (int j = 0; j < width; j++)
        board[i][j] = row[j] - '0';
}
```

### 3-6. 큰 수 덧셈

`long long`(약 9.2 × 10¹⁸)도 넘는 수는 문자열로 자리수마다 더한다. 꺼낼 때 `- '0'`, 다시 넣을 때 `+ '0'`을 쓴다.

```cpp
#include <algorithm>  // reverse

string AddBig(string a, string b) {
    string result;
    int i = a.size() - 1, j = b.size() - 1, carry = 0;
    while (i >= 0 || j >= 0 || carry) {
        int sum = carry;
        if (i >= 0) sum += a[i--] - '0';
        if (j >= 0) sum += b[j--] - '0';
        result.push_back(sum % 10 + '0');   // 정수 → 문자
        carry = sum / 10;
    }
    reverse(result.begin(), result.end());
    return result;
}

cout << AddBig("99999999999999999999", "1");
// 출력: 100000000000000000000
```

> **새 문법: `a[i--]`**
> `a[i]`를 먼저 사용하고 그다음 `i`를 1 줄인다.

> **새 문법: `reverse(시작, 끝)`**
> 범위의 순서를 뒤집는다. 뒤 자리부터 더해서 결과가 거꾸로 쌓였기 때문에 마지막에 한 번 뒤집는다.

### 3-7. 같은 원리: 알파벳 → 0~25

알파벳도 코드가 연속이라 같은 방식으로 배열 인덱스를 만든다. 알파벳 개수 세기 문제에서 쓴다.

```cpp
string word = "abz";
for (char c : word) cout << c - 'a' << ' ';
// 출력: 0 1 25

int alphabet_count[26] = {};
for (char c : word) alphabet_count[c - 'a']++;   // 알파벳별 개수
```

## 4. 관련 표현 및 함수

| 표현/함수 | 용도 | 예시 | 헤더 |
|---|---|---|---|
| `c - '0'` | 숫자 문자 → 정수 | `'7' - '0'` → `7` | 없음 |
| `n + '0'` | 0~9 정수 → 숫자 문자 | `char c = 7 + '0';` → `'7'` | 없음 |
| `c - 'a'` | 소문자 → 0~25 | `'z' - 'a'` → `25` | 없음 |
| `stoi(s)` | 문자열 → `int` | `stoi("123")` → `123` | `<string>` |
| `stoll(s)` | 문자열 → `long long` | `stoll("12345678901")` | `<string>` |
| `to_string(n)` | 정수 → 문자열 | `to_string(123)` → `"123"` | `<string>` |
| `isdigit(c)` | 숫자 문자인지 검사 | `isdigit('3')` → 참 | `<cctype>` |

---

## 5. 주의사항

1. **한 글자에만 쓴다.** `"123" - '0'`은 안 된다. 순회하면서 각 `char`에 적용한다.
2. **숫자 문자가 아니면 의미 없는 값이 나온다.** `'a' - '0'`은 49다. 입력에 다른 문자가 섞일 수 있으면 `isdigit()`으로 먼저 거른다.
3. **원본은 바뀌지 않는다.** `c - '0'`은 새 값을 만들 뿐이고 `c`는 그대로 `char`다.
4. **`n + '0'`은 0~9에서만 맞다.** `12 + '0'`은 `'<'`가 된다. 두 자리 이상은 `to_string()`을 쓴다.
5. **`char` 변수에 저장하면 출력이 달라진다.**
   ```cpp
   char x = '3' - '0';
   cout << x;        // 숫자 3이 아니라 코드 3번 제어문자가 출력됨
   cout << (int)x;   // 출력: 3
   ```
   결과는 `int` 변수에 담는다.
6. **격자 입력에서 `cin >> board[i][j]`로 받으면 안 된다.** `0110`을 숫자 하나(110)로 읽어버린다. 줄을 `string`으로 받고 `- '0'`으로 나눈다.

## 6. 암기 한 줄

```
숫자 문자 → 정수: c - '0'    /    정수 → 숫자 문자: n + '0'    /    소문자 → 인덱스: c - 'a'
```
